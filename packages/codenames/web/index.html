Jev plays Codenames

A spymaster that knows what it doesn't know. Every card shows the probability TypeSafe's Jev assigned; the thresholds decide the play.

agent bystander assassin probability 0 to 1 uncertain band 0.30 to 0.70

The board lights up as you type: one request, 25 nouls and a choice, about 300 ms.

Jev's probabilities stay hidden until your turn ends, then the board shows what it was thinking.

The policy, in code

A friendly word counts toward the clue's number at 0.70 or above. Between 0.30 and 0.70 it is uncertain and never counted. A clue is rejected if the assassin is above 0.10 or any bystander is above 0.40. Jev only answers "does this clue reach this word"; everything else is code.

    Built on TypeSafe Jev through the direct API. Code and the offline evaluation against 7,703 human turns: jev-lab/packages/codenames.
