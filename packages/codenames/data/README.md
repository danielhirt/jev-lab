# data

Generated files live here and are ignored by git.

- `salt-duet.jsonl`: human clue rows converted from the SALT-NLP Codenames Duet corpus by `eval/salt.ts`. The source repository states no license, so the derived file is not committed; regenerate it from a clone.
- `cache-<model>.json`: judgments cached by `CachingJudge`, so evals and demos replay without spend.
